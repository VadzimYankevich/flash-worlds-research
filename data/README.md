# Данные и происхождение

Все JSON сохраняются в UTF-8. CSV используют заголовок и десятичную точку; единица времени в колонках `seconds` — секунды, в `milliseconds` — миллисекунды. Исторические файлы не меняются при повторном запуске.

| Группа | Назначение |
|---|---|
| `benchmark_original.json` | Исходные 36 наблюдений, параметры, порядок, медианы, парные результаты, точные снимки программ |
| `benchmark_original_*.csv` | Те же наблюдения, медианы и парные отношения в табличном виде |
| `benchmark_rerun.json`, `benchmark_rerun_*.csv` | Отдельный повтор неизменённого протокола; времена не подменяют исходные |
| `fast_engine_diagnostic.json`, `segmented_engine_diagnostic.json` | Дополнительные одиночные запуски с `--profile`: счётчики работы и независимая проверка ответов; их времена не включены в парное сравнение |
| `record_original.json` | Исходные `E`, окно и предел простых, каждый фактор, индексы неизвестных, код и точный протокол |
| `record_rerun.json` | Повтор символического расчёта с теми же входами |
| `mathematics_checks.json` | Сохранённая конечная проверка математических тождеств и точного покрытия |
| `mathematics_rerun.json` | Повтор математических проверок через `run_all.py` |
| `demo_selfcheck.json` | Отдельная проверка учебной реализации, включая псевдопростые |
| `ripple_depth.json`, `ripple_depth.csv`, `ripple_depth_activity.csv` | Левые границы полных суффиксов, выбранные разреженные покрытия, остаточные слои и возвращение осей в точном малом пилоте |
| `ripple_1013.json` | Три специально выбранных мира: активность, полное поглощение непустого следа и возвращение оси 1013 |
| `ripple_smooth_certificate.json`, `ripple_smooth_certificate.csv` | Полные малые части 1500 рекордных адресов, точные степени простых, сертификат поглощения всех осей до миллиона и границы a* |
| `ripple_*_rerun.json`, соответствующие CSV | Повторы новых проверок через `run_all.py`, отдельно от первоначальных протоколов |
| `figure_inputs.json` | Все точки координатного рисунка, значения графика времени, адреса и стадии видео |
| `resources.json` | Исходный снимок CPU/памяти/доступа к GPU и вычисленный масштаб полного базиса |
| `resources_rerun.json` | Ресурсы машины при повторном запуске |
| `reproduction_rerun.json`, `package_verification.json` | Сводки запуска пакета; их времена являются служебными, а не сравнением движков |

В `record_*` отсутствие найденного делителя представлено `null`/индексом в списке неизвестных. Это **UNKNOWN**, а не простое. Предел простых задаётся в `input.small_prime_limit`; граница и формула адреса — в соседних полях. Гигантские оценки в `resources*.json` хранятся строками и помечены как асимптотические.

В `benchmark_*_summary.csv` отношение равно времени `numerator`, делённому на время `denominator`, сначала в каждом раунде. Колонка медианы затем агрегирует полученные отношения. Это не отношение двух отдельных медиан.

`figure_inputs.json` является воспроизводимым входом для интерпретации рисунков и видео; генератор заново получает эти значения из неизменённых `benchmark_original.json` и `record_original.json` и заданной координатной модели. Файлы с `rerun` можно обновлять; `original` предназначены для неизменяемого исходного свидетельства.

Дополнительный рисунок `ripple_absorption` строится из `additional_valid_flash_transition` в `ripple_depth.json`. Он показывает только след оси 5 и его остаток; нейтральные точки не обозначают доказанных простых.
